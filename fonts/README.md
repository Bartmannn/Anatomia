# Czcionki

Pliki czcionek używanych na stronie, żeby nie łączyć się z serwerami Google przy każdym wejściu.

| Czcionka | Autorzy | Licencja |
|---|---|---|
| Archivo | The Archivo Project Authors (Omnibus-Type) | SIL Open Font License 1.1 (`OFL-archivo.txt`) |
| Hanken Grotesk | The Hanken Grotesk Project Authors | SIL Open Font License 1.1 (`OFL-hankengrotesk.txt`) |
| JetBrains Mono | The JetBrains Mono Project Authors | SIL Open Font License 1.1 (`OFL-jetbrainsmono.txt`) |

Pliki woff2 pochodzą z Google Fonts (podzbiory znaków `latin` i `latin-ext`), bez zmian. Deklaracje są w `fonts.css`.
